# AnoTerm

**日本語** | [English](README.en.md)

Android 向けの SSH クライアント / ターミナルエミュレータ。Kotlin + Jetpack Compose。

日本語・中国語を含む**全角文字を正しい幅で描画する**ことを主眼にしている。Android の
ターミナルアプリで CJK を扱うと、カーソル位置がずれて表示が崩れることが多い。
文字幅の計算と UTF-8 のデコードを自前で実装しているのはそのため。

## 機能

### 端末として

- **全角・結合文字を正しい幅で描く** — `CharWidth.kt` が East Asian Width を解決し、
  `Utf8Decoder.kt` がサロゲートペアと不完全なバイト列を扱う。Android のターミナルで
  CJK を扱うとカーソル位置がずれて崩れることが多く、これを自前で実装しているのはそのため
- **ターミナルエミュレーション** — `TerminalEmulator.kt`。代替画面、スクロール領域、
  マウス報告、DECCKM などに対応
- **履歴の検索** — ⋮ メニューから。この接続で流れた文字を探す（シェルの履歴でも
  ファイルの中身でもない）。一致は塗られ、矢印で行き来できる
- **惰性スクロール** — 勢いよく払えば流れる。遡っている間は「何行前」のボタンが出て、
  押せば最新に戻る
- **画面の高さが変わっても読んでいる行が動かない** — キーボードやバーの出入りで
  行数が変わるとき、溢れた行は捨てずにスクロールバックへ送り、広がるときは引き戻す。
  履歴を読んでいる間は上端が固定される

### 接続と認証

- **接続先の管理** — ホスト・ポート・ユーザー名を保存（Room）
- **認証** — パスワードと秘密鍵の両方。パスフレーズ付き鍵にも対応
- **公開鍵の登録（`ssh-copy-id` 相当）** — パスワードで繋がっている接続を使い、
  公開鍵を接続先の `~/.ssh/authorized_keys` に追記する。Android だけで鍵認証に移れる。
  二重登録はせず、既存の鍵も壊さない
- **ホスト鍵の検証（TOFU）** — 初回の鍵を記録し、**変わったら接続を拒否する**。
  初回接続時には記録した指紋を表示するので、サーバー側の `ssh-keygen -lf` と
  突き合わせて確認できる
- **資格情報の暗号化保存** — Android Keystore の鍵で `EncryptedFile`
- **アプリロック** — 生体認証（任意）
- **バックグラウンド接続** — フォアグラウンドサービスで画面 OFF 中も維持

### tmux

- **自動 attach** — ホスト設定でセッション名を入れておくと、接続後に
  `tmux new -A -s <名前>` を送る。切断されても作業が残る
- **ウィンドウ一覧（≡）** — 左から出る抽斗に、開いている全接続の全ウィンドウが
  接続 → セッション → ウィンドウの 3 階層で並ぶ。**どこのウィンドウでも 1 タップで飛べる**。
  更新のあったウィンドウには印が付き、中で動いているコマンドも出る
- **切り替えバー** — 今いる接続の tmux ウィンドウが並ぶ。1 タップで背面へ移れる。
  ⋮ メニューから隠せる
- **prefix キーを一切送らない** — tmux 操作は全て `tmux` コマンドの実行。前面のアプリが
  Ctrl-B を握っていても効き、`.tmux.conf` で prefix を変えていても関係ない
- 一覧は端末に打ち込むのではなく別の SSH セッションで読むので、作業中の画面に
  出力が混ざらない

### 手元で確かめる

- **画像を開く** — 端末に出たパスに下線が付き、押すとその画像が出る。Claude Code や
  Codex が図やスクリーンショットを書き出しても、端末に残るのはパスだけで、
  スマホからは中身を確かめようがなかった。ピンチで拡大
- **文書を開く** — `.md` `.kt` `.json` `.diff` など 50 種あまり。行番号付き・折り返し無し
  （コードを折り返すと字下げが崩れて構造が読めない）
- **ページを隣で見る** — `http://` の URL を押すと端末の隣にブラウザが開く。
  **通信はこの SSH 接続の中を通す**ので、`localhost` にしか口を開けていない開発サーバーも
  外に晒さずに見られる。待ち受けは端末内の 127.0.0.1 に限定。上下・左右どちらの分割にもでき、
  仕切りをドラッグして配分を変えられる。端末のブラウザに渡して全画面でも見られる
- 読み込みはどれも**作業中のシェルとは別の SSH セッション**なので、コマンドラインに
  余計な出力が混ざらない。相対パスは tmux のペインの現在地から探す

### 狭い画面のための設計

- **端末だけの全画面** — 上のバーも tmux の行もステータスバーも消える。ダブルタップで
  行き来し、1 回タップすると右上に縮小アイコンが数秒出る。戻る操作でも抜けられる
- **タブは上のバーの中** — タブの名前は「今どの接続にいるか」で、バーの見出しと役割が
  重なる。1 行に畳んである
- **浮かぶ返答パッド** — キーボードを閉じている間、端末の上に 1/2/3 と Esc とキーボードを
  重ねる。承認プロンプトに答えるためだけに IME を開いて本文を隠す必要がなくなる。
  つまみの長押しで**方向キーと決定**に入れ替わる（一覧を動いて選ぶ用）。好きな位置へ動かせる
- **打っている間だけ出る補助キー** — Esc・矢印・Ctrl・⇧Tab などはキーボードと一緒に
  出入りする。読んでいる間まで置いておくには画面が狭い
- **内側カメラを避ける** — 折りたたみを開いた画面の中にあるカメラに文字が食われないよう、
  システムが報告するカットアウトのぶん自動で避ける。足りなければ左端の余白を設定できる
- **触った所にカーソル** — 相手がマウス報告を要求している間（Claude Code、vim、
  mouse on の tmux）、タップした位置にカーソルが移る

### その他

- **ジェスチャ** — 下 1/4 タップでキーボード、スワイプでスクロール（勢いよく払えば流れる）、
  ダブルタップで全画面の行き来、長押しドラッグで範囲選択とコピー、ピンチで文字の大きさ。
  下線の付いたパスや URL はタップで開く。全部ヘルプに載っている
- **コマンド履歴**、**メモ**、**独自ショートカット**
- **表示のカスタマイズ** — 文字の大きさ（ピンチでも変わり、そのまま保存される）、行間、配色

## 表示言語

英語と日本語。既定は端末の設定に従い、設定画面で切り替えられる（アプリを
再起動する必要はない）。

文言は全て `strings.xml` にある。Kotlin に直接書かれた文字列は残っていない。
`tools/check-strings.py` が CI で、キーの重複・片方の言語にしかないキー・
書式引数の不一致・どこからも参照されていないキーを検査する。

ターミナルの表示内容は接続先が出すものなので、この設定の影響を受けない。

## 動作条件

- Android 7.0 (API 24) 以上
- JetBrains Mono を同梱しているため、端末側のフォント設定に依存しない

## インストール

### APK を入れる（推奨）

[Releases](https://github.com/mirute02/wanoterm/releases) から `app-release.apk` を
Android 端末のブラウザでダウンロードし、通知またはファイルアプリからタップする。
PC も adb も要らない。

初回は「提供元不明のアプリ」の許可を求められる。Android 8.0 以降はアプリ単位の
許可なので、ブラウザやファイルアプリに対して一度許可すればよい。

Play ストア経由ではないため、Play Protect が確認画面を出すことがある。
署名は自己署名。証明書はここに書いておく（リリースごとの記載を約束すると、
書き忘れた版で嘘になる。1 か所に置いて変えないほうが確かめやすい）:

```
CN=AnoTerm, OU=AnoTerm, O=AnoTerm, C=JP
SHA-256: 7e1677c2e1094ca36b9584990beabb2fb1668b327417ead3b0993ec1b99bbbdb
```

手元の APK と突き合わせるには `apksigner verify --print-certs <apk>`。
**この指紋は変えられない。** 鍵が変わったアプリは Android から別アプリとして扱われ、
上書き更新ができなくなる。異なる指紋の APK は、このプロジェクトのものではない。

### 自分でビルドする

```bash
git clone https://github.com/mirute02/wanoterm.git
cd wanoterm
./gradlew assembleDebug
```

`app/build/outputs/apk/debug/app-debug.apk` ができる。
署名鍵を持たない環境ではリリース版は署名なしになるため、配布用には使えない。

## ビルド

```bash
./gradlew assembleDebug
```

`namespace` / `applicationId` は `app.anoterm`（デバッグビルドは `.debug` サフィックス）。

### テスト

```bash
./gradlew test
```

単体テストが 124 件ある。CI で毎回実行している。対象は、ターミナルエミュレーション、
文字幅計算、UTF-8 デコード、IME の未確定文字列、画面のリサイズで行が失われないこと、
端末に出たパスや URL の切り出し（折り返しを跨ぐ結合、シェルクォート）、tmux の出力の解析、
ポート転送の宛先の組み立て。

実機に繋げない環境で開発しているため、**目で見なければ分からない部分は
テストで固めていない**。ロジックとして切り出せるものは切り出してテストに載せる方針で、
描画や入力の手触りはリリースを実機に入れて確かめている。

### リリースビルド

署名鍵はリポジトリに含めない。`gradle.properties`（または CI の Secrets）に置く:

```properties
WANOTERM_STORE_FILE=/absolute/path/to/release.jks
WANOTERM_STORE_PASSWORD=...
WANOTERM_KEY_ALIAS=...
WANOTERM_KEY_PASSWORD=...
```

証明書の DN は APK から誰でも読めるので、本名ではなくプロジェクト名を入れること。
一度配布した鍵は変更できない。詳細は [docs/RELEASE_SIGNING.md](docs/RELEASE_SIGNING.md)。

`app/build.gradle.kts` の `signingConfigs` は `project.findProperty()` 経由で読むため、
プロパティが無い環境では署名なしビルドになる。クローン直後でもビルドが通る。

詳細は [docs/RELEASE_SIGNING.md](docs/RELEASE_SIGNING.md)。

## セキュリティ

SSH クライアントは接続先の資格情報を預かり、その鍵で任意のコマンドを実行できる
端末になる。[docs/security.md](docs/security.md) に、暗号化して保存していること、
ホスト鍵が変わったら**警告して続行するのではなく拒否する**こと、そして端末の
ロックを破られた場合は資格情報が取り出されうるという限界を書いてある。

プライバシーポリシーは [docs/PRIVACY_POLICY.md](docs/PRIVACY_POLICY.md)。
